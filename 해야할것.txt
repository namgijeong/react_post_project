React Hook Form은 입력값을 상태(state)에 저장하지 않고
DOM의 ref를 사용해서 값(value)을 직접 추적합니다.
즉, 일반 Controlled Component처럼 useState로 매번 렌더링하지 않고,
입력 중에는 컴포넌트가 재렌더링되지 않음 → 성능 최적화
register를 통해 input에 ref가 붙음
입력값은 DOM에 저장되고 React state에는 저장되지 않음
입력 중에는 컴포넌트 재렌더링 없음
handleSubmit이나 getValues() 호출 시점에 값 가져옴
